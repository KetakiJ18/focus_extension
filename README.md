# Focus Companion Chrome Extension

## 🚀 Overview
A productivity-focused Chrome extension designed to reduce distractions, improve attention span, and promote mindful browsing.

## ✨ Features
- Intent-based browsing prompts
- Smart delay for distracting sites
- Real-time productivity tracking
- GitHub-style heatmap visualization
- Custom new tab dashboard with focus stats

## 🧠 How It Works
- Detects when user opens distracting websites
- Prompts user intent (learn/work vs scrolling)
- Tracks session duration based on user choice
- Stores daily stats locally

## 📊 Metrics Tracked
- Productive time (minutes)
- Mindless browsing time
- Daily usage trends

## 🏗️ Tech Stack
- JavaScript (Vanilla)
- Chrome Extension APIs (Manifest V3)
- HTML/CSS
